# Science Camp Lab｜科普營隊營運模擬平台

國立高雄大學學生團隊的科普營隊試營運工作空間。以可調整的假設模型，整理財務、排程、風險與真實營運紀錄。

- 手機／桌面測試：[開啟網站](https://YunCheHsieh.github.io/science-camp-lab/)
- 原始碼：[GitHub](https://github.com/YunCheHsieh/science-camp-lab)

## 本機執行

需要 Node.js 24 及 npm。

```sh
npm ci
npm run dev
```

開啟 http://localhost:3000 。正式靜態建置：`npm run build`，輸出到 `out/`。這是靜態匯出的 Next.js 應用，不能使用 `next start`；正式輸出可由任何靜態 HTTP 伺服器提供。

```sh
npm test
npm run typecheck
npm run lint
npm run build
```

## 功能

1. **營運總覽**：五項 KPI、月營收／成本圖、收入配置、快速模擬及準備進度。
2. **營隊參數**：滑桿與數字輸入、學生／公司模式、師資及所有成本設定、容量與目標。
3. **損益兩平**：最低人數、價格、場數、平均招生與目標場數，含容量及不可行提示。
4. **年度排程**：12 個月、多方案／梯次、複製方案、每月教室及人日容量、三種月度圖表。
5. **情境比較**：三組各自完整設定、收入／成本／留存比較與教學日需求。
6. **風險分析**：招生率 50–100%、價格與招生熱力圖、八種可調整壓力測試。
7. **試營運路線圖**：四階段、21 項可勾選任務與完成百分比。
8. **實際紀錄**：新增、編輯、刪除、預算快照、預實差異、CSV 匯入預覽與匯出。
9. **公司化評估**：人事、租金、行政、折舊、目標及額外營運需求。
10. **結果報告**：即時產生完整報告、列印／透過瀏覽器另存 PDF、JSON 報告資料。

## 建議手機驗收流程

1. 總覽預設應為年度營收 **NT$512,000**、預估留存 **NT$110,080**。
2. 將每場學生改為 25 人，營收應即時變成 **NT$640,000**，留存 **NT$190,880**。
3. 選單進入年度排程，新增或修改一個月份的方案，再將「總覽／報告來源」改為年度排程加總。
4. 勾選路線圖任務後重新整理，確認進度保留。
5. 新增真實活動紀錄，匯出 CSV；再次匯入會預覽，使用相同 ID 更新而非新增重複紀錄。
6. 開啟結果報告，點選「列印／另存 PDF」。手機 PDF 儲存方式依瀏覽器與系統提供。

## 計算口徑

所有核心財務函式位於 `src/lib/finance.ts`，不依賴 React、日期或瀏覽器。

- 直接成本 = 講師 + 助教 + 場地 + 器材 + 招生行政 + 學生變動成本 + 排程額外支出。
- 總成本 = 直接成本 + 另付規劃酬勞 + 公司固定支出。
- 營運結餘 = 營收 − 總成本。
- 預估留存 = 營運結餘 − 風險準備金。
- **準備金是資金預留，不是已發生的會計費用。**
- 金額以分為精度；輸入單價與單場各成本四捨五入後加總，年度依場次／月份加總。
- 損益兩平使用扣除準備金後的留存。人數及場數向上取整；最低價格向上取至分。
- 基本參數的最低人數會分攤年度固定成本至指定場數；最低場數則以每場貢獻覆蓋全年固定成本。
- 固定成本為 0 且單場有正貢獻時，**0 場**代表沒有活動也不虧損；不代表能產生收入。負或零單場貢獻會明確顯示無法靠增加場數達標。
- 公司模式預設每月 NT$125,000，規劃工作包含在固定薪資。有額外外部規劃費可取消勾選，避免同一份核心團隊薪資重複計算。
- 公司評估的預設固定支出：3 × 35,000 × 110% + 5,000 + 3,500 + 1,000 = 125,000。
- 公司化的額外委託需求顯示**淨貢獻**，不是忽略成本的委託營收。
- 各月固定支出只計一次，即使沒有營隊仍計入。不同方案繼承共用時薪、時數及非覆寫成本。
- 週末容量是可用週末 × 2 天 × 教室數；人力以總人日檢查。**未驗證具體日期、同時上課或師資衝突。**
- 累積現金流假設期初 0、當月收付款，已扣預留資金；尚未建模預收款、稅務、資本支出、融資與付款時差。
- 公司折舊為非現金成本，此頁的留存是保守資金指標，非正式現金流量表。

## 資料保存與隱私

不需要帳號、伺服器資料庫或付費。所有資料保存在目前瀏覽器的 `localStorage`（鍵值 `science-camp-lab:v1`）。**手機與電腦不會自動同步。** 使用側欄的 JSON 備份／還原可轉移完整設定。無痕模式、清除網站資料或換裝置可能失去資料，請定期備份。

備份與 CSV 使用 Zod 驗證：拒絕非有限、負數、錯誤日期、付費人數超過報名、退費超過實收或不完整欄位。CSV 採 UTF-8 BOM，支援中文、引號及換行，輸出會處理試算表公式注入。保留 `expected` 欄位即可完整還原每場預算快照。單次匯入上限 5,000 筆，10 MB。JSON 上限 20 MB。CSV 不包含家長個資。

基礎參數、排程、情境互不覆寫；報告明確標示選用的資料來源。每個實際活動的 `expected` 保存當時預算，不隨目前參數變更。

## 架構

```text
src/app/                 Next.js App Router、全站樣式
src/components/lab/      應用外殼、共用控制項與十個功能模組
src/components/ui/       shadcn/ui（Base UI）元件
src/lib/finance.ts       共用純函式財務引擎
src/lib/state.ts         型別、Zod 驗證、預設值及路線圖
src/lib/use-store.ts     版本化 localStorage 保存與錯誤處理
src/lib/csv.ts           CSV 驗證、匯入、匯出及下載
src/lib/*.test.ts        財務與資料完整性單元測試
.github/workflows/       檢查、測試、建置與 GitHub Pages 部署
```

Next.js、React、TypeScript、Tailwind CSS 4、shadcn/ui、Recharts、Lucide。進階模組按需載入，系統字型不依賴外部 Google Fonts。已指定開發工具相依 minimatch 修補版，以避免已知漏洞。

## GitHub 自動部署

推送到 `main` 後，GitHub Actions 依序安裝、型別檢查、lint、單元測試、正式建置並部署 Pages。`NEXT_PUBLIC_BASE_PATH=/science-camp-lab` 配合專案網址。若更改儲存庫名稱，請同步修改 workflow 的 base path。

官方參考：[Next.js 靜態匯出](https://nextjs.org/docs/app/guides/static-exports)、[GitHub Pages 自訂 workflow](https://docs.github.com/en/pages/getting-started-with-github-pages/using-custom-workflows-with-github-pages)、[shadcn/ui](https://ui.shadcn.com/docs)。

## 視覺基準與限制

視覺基準及設計決策見 `docs/DESIGN.md` 與 `docs/design-concept.png`。概念圖為設計參考，實際 UI 全部為可操作的程式元件。圖表數值、KPI 標籤及路線圖內容依需求及共用計算引擎修正，不採用生成圖的錯誤數字或未驗證商業結論。

本專案所有結果均為假設模型。已提供可用 MVP 與進階試算工具，但不包含登入、多裝置同步、實際報名收款、稅務申報或真正的市場驗證。
