# Science Camp Lab — Design contract

Reference: `design-concept.png` (1536 × 1024), generated with the built-in Image Gen tool. User specification is authoritative for labels, calculations and features.

- White sidebar, cool gray #f7f9fc workspace, navy #142b49 type and charts, teal #159c8f emphasis; no gradients or photography.
- Desktop sidebar 232px; 32px workspace gutters; 12px bordered panels. On mobile use an accessible drawer, two-column KPI grid, single-column charts and forms, locally scrollable tables.
- System sans / Noto Sans TC / Microsoft JhengHei; headings 28px, panel titles 18px, body 16px, labels 14px, metadata 12px. Tabular figures, explicit button typography.
- Lucide outline icons, 18–22px, consistent 1.8px stroke. FlaskConical brand icon is vector UI, no raster asset required.
- Primary surface: breadcrumb, title and mode selection, five KPIs, monthly forecast and cost allocation, reserve explanation, quick settings and roadmap, accounting table.
- Navigation: 營運總覽、營隊參數、損益兩平、年度排程、情境比較、風險分析、試營運路線圖、實際紀錄、公司化評估、結果報告.
- All secondary modules extend the same panel, table, field, alert and chart system; no unrelated marketing sections.
- Intentional corrections to generated concept: use actual financial values rather than generated chart data; distinguish retention from profit; KPI uses requested break-even event count; roadmap begins unchecked and uses the user's exact tasks; replace unsupported claims of business viability with model assumptions.
- Functional additions required by the user: data-source selection, versioned autosave, backups, validation, report printing, capacity warnings, CSV import preview.

Prompt brief: full Traditional Chinese science education financial dashboard, white/navy/teal, full ten-module sidebar, five live KPI cells, monthly revenue/cost bars, cost allocation donut, quick sliders, roadmap; practical responsive HTML/React implementation, no decorative assets or fabricated business claims.
